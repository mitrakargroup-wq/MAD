# Mitrakar Architectural Designers
Static multi-page site (HTML/CSS/JS), no build step. Vercel: Framework Preset "Other", leave build command and output directory empty.
Edit content in `data.js` (services, industries, projects, posts, contact config).
Forms: set `CFG.FORM_ENDPOINT` in `data.js` (e.g. a Formspree endpoint). Until set, forms open the visitor's email app.
